# 单管电流镜
![20261109203555](https://raw.githubusercontent.com/shenguosai/MyPic/img/img/20261109203555.png)
$\frac{I_{out}}{I_{in}} = \frac{(W/L)_2}{(W/L)_1}$
输出阻抗：$r_{out} = r_{o2}$
优点：结构简单；输出摆幅大 $V_{out,min} > V_{DSAT2}$；
不足：M2 输出阻抗小，镜像电流受 $V_{out}$ 电压影响大
# Cascode 电流镜
![20261109204443](https://raw.githubusercontent.com/shenguosai/MyPic/img/img/20261109204443.png)
$\frac{I_{out}}{I_{ref}} = \frac{(W/L)_2}{(W/L)_1}$
输出阻抗：$r_{out} = r_{o2}g_{m4}r_{o4}$
优点：M4 屏蔽了 Vout 对 M2 的影响，输出阻抗提高
不足：$V_B = 2V_{gs}$, $V_{out,min} > 2V_{DSAT} + V_{TH}$，故输出摆幅很小
# 宽摆幅 Cascode 电流镜
![20261109204838](https://raw.githubusercontent.com/shenguosai/MyPic/img/img/20261109204838.png)
$\frac{I_out}{I_ref} = \frac{(W/L)_2}{(W/L)_1}$
输出阻抗：$r_{out} = r_{o2}g_{m4}r_{o4}$
优点：$V_B$可取小一点，大于$V_{GS4}+V_{DSAT2}$即可，有$V_{out,min} > V_B-V{TH}$， 即$V_{out,min} > V_{GS4}-V_{TH}+V_{DSAT2}$，即$V_{out,min} > 2V_{DSAT}$，摆幅提升。
不足：需提供额外的V_B偏置电压。
# 威尔逊电流镜
![20261109205822](https://raw.githubusercontent.com/shenguosai/MyPic/img/img/20261109205822.png)
$\frac{I_out}{I_ref} = \frac{(W/L)_2}{(W/L)_1}$
输出阻抗：$r_{out} \approx r_{o2}g_{m4}r_{o4}$
优点：负反馈稳定$V_X$和$V_Y$两点电压，稳定程度高于Cascode结构。
缺点：$V_Y$始终比$V_X$高一个$V_{GS}$，Iout 始终低于理想值（M2的$V_{DS}$ < M4的$V_{DS}$）。$V_Y = 2V_{GS}$，$V_{out,min} > V_{GS} + V_{DSAT} => V_{out,min} > V_{TH} + 2V_{DSAT}$，摆幅较小。
