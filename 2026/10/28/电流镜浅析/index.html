电流镜浅析

发表于2026-10-28|更新于2026-11-09|半导体专业模拟电路
|浏览量:

单管电流镜


$\frac{I_{out}}{I_{in}} = \frac{(W/L)2}{(W/L)1}$
输出阻抗：$r{out} = r{o2}$
优点：结构简单；输出摆幅大 $V_{out,min} > V_{DSAT2}$；
不足：M2 输出阻抗小，镜像电流受 $V_{out}$ 电压影响大

Cascode 电流镜


$\frac{I_{out}}{I_{ref}} = \frac{(W/L)2}{(W/L)1}$
输出阻抗：$r{out} = r{o2}g_{m4}r_{o4}$
优点：M4 屏蔽了 Vout 对 M2 的影响，输出阻抗提高
不足：$V_B = 2V_{gs}$, $V_{out,min} > 2V_{DSAT} + V_{TH}$，故输出摆幅很小

宽摆幅 Cascode 电流镜


$\frac{I_out}{I_ref} = \frac{(W/L)2}{(W/L)1}$
输出阻抗：$r{out} = r{o2}g_{m4}r_{o4}$
优点：$V_B$ 可取小一点，大于 $V_{GS4}+V_{DSAT2}$ 即可，有 $V_{out,min} > V_B-V{TH}$， 即 $V_{out,min} > V_{GS4}-V_{TH}+V_{DSAT2}$，即 $V_{out,min} > 2V_{DSAT}$，摆幅提升。
不足：需提供额外的 V_B 偏置电压。

威尔逊电流镜


$\frac{I_out}{I_ref} = \frac{(W/L)2}{(W/L)1}$
输出阻抗：$r{out} \approx r{o2}g_{m4}r_{o4}$
优点：负反馈稳定 $V_X$ 和 $V_Y$ 两点电压，稳定程度高于 Cascode 结构。
缺点：$V_Y$ 始终比 $V_X$ 高一个 $V_{GS}$，Iout 始终低于理想值（M2 的 $V_{DS}$ < M4 的 $V_{DS}$）。$V_Y = 2V_{GS}$，$V_{out,min} > V_{GS} + V_{DSAT} => V_{out,min} > V_{TH} + 2V_{DSAT}$，摆幅较小。
